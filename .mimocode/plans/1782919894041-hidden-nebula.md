# Жалған деректер мен логикалық қателіктерді түзету жоспары

## Фаза 1: RatingView — жалған деректерді нақты дерекпен алмастыру

**Мәселе:** RatingView-да 10 адамның аты және баллы жалған. Firebase-ден нақты дерек түспейді.

**Шешім:** `users` коллекциясынан барлық пайдаланушыларды алып, олардың `test_results` ішіндегі ең жоғары баллы бойынша сұрыптау.

**Файлдар:**
- `Services/HistoryService.swift` — `fetchTopUsers()` method қосу
- `Views/Rating/RatingView.swift` — жалған деректерді нақтымен алмастыру

**Firestore сұранысы:**
```
users коллекциясы → әр пайдаланушының test_results подколлекциясы → ең жоғары score
```

**Логика:**
1. `HistoryService.fetchTopUsers()` — барлық пайдаланушылардың ең жоғары баллдарын алады
2. `RatingView` — `onAppear`-да Firebase-ден жүктейді
3. Егер дерек жоқ болса — "Әлі ешкім тест тапсырмады" көрсетеді

## Фаза 2: ProfileView — hardcoded телефонды алып тастау

**Мәселе:** `+7 (747) 850 18 22` hardcoded. Пайдаланушының нақты телефоны көрсетілмейді.

**Шешім:** `UserProfile`-ке `phone` қосу, ProfileView-да `authViewModel.user?.phone` қолдану.

**Файлдар:**
- `Models/UserProfile.swift` — `phone: String?` қосу
- `Services/AuthService.swift` — `signUp()` және `createPhoneProfile()` ішінде phone сақтау, `decodeProfile()` ішінде phone оқу
- `Views/Profile/ProfileView.swift` — hardcoded телефоны алып тастау

## Фаза 4: ActiveTest — профиль пәндерін сақтау

**Мәселе:** Тест жалғастырғанда мамандықты білу керек, бірақ `ActiveTest`-те профиль пәндері жоқ.

**Шешім:** `ActiveTest`-ке `profile1` және `profile2` қосу. `TestViewModel`-да сақтау.

**Файлдар:**
- `Models/ActiveTest.swift` — `profile1: String`, `profile2: String` қосу
- `ViewModels/TestViewModel.swift` — `startTest()` кезінде профильдерді сақтау
- `Services/AuthService.swift` — `saveActiveTest()` және `fetchActiveTest()` жаңарту

## Фаза 5: TestSetupView — "1 пән" мен "Толық КТ" айырмашылығы

**Мәселе:** Екеуі де бірдей `startTest()` шақырады, айырмашылық жоқ.

**Шешім:**
- "1 пән" — бір ғана профиль пәні бойынша тест (50-60 сұрақ, 60 минут)
- "Толық КТ" — барлық пәндер бойынша тест (130 сұрақ, 235 минут)

**Файлдар:**
- `ViewModels/TestViewModel.swift` — `startSingleSubjectTest()` method қосу
- `Views/Test/TestSetupView.swift` — екі батырманы әртүрлі функцияға байлау

**Логика:**
- `startSingleSubjectTest()` — бір ғана `profileSubject()` шақырады
- `startTest()` (толық КТ) — `generateFullTest()` шақырады

## Фаза 8: AIService — API key мәселесі

**Мәселе:** `ProcessInfo.processInfo.environment["DEEPSEEK_API_KEY"]` Simulator-да жұмыс істемейді.

**Шешім:** `Bundle.main.infoDictionary`-дан алу. Info.plist-те `DEEPSEEK_API_KEY` бар.

**Файлдар:**
- `Services/AIService.swift` — `apiKey` computed property жаңарту

---

## Фаза 9: HistoryView — specialtyCode табу мәселесі

**Мәселе:** `specialtyName(for:)` function `subjectBreakdown`-дан код іздейді, бірақ ол `SubjectId.rawValue` болып сақталады, `SpecialtiesData.byCode()` таппайды.

**Шешім:** `SavedTestResult`-ке `specialtyCode` өрісін қосу. HistoryView-да соны қолдану.

**Файлдар:**
- `Models/SavedTestResult.swift` — `specialtyCode: String?` қосу
- `Views/Result/ResultView.swift` — `saveToHistory()` кезінде `specialtyCode` жазу
- `Views/History/HistoryView.swift` — `specialtyCode`-дан атау алу

---

## Фаза 10: ResultView — AuthService.shared access

**Мәселе:** `AuthService.shared.currentUser?.uid` actor isolation мәселесі болуы мүмкін.

**Шешім:** `ResultView`-ға `userId` параметрін беру немесе `await` қолдану.

**Файлдар:**
- `Views/Result/ResultView.swift` — `saveToHistory()` жаңарту

## Тексеру

1. `xcodegen generate` → `xcodebuild build` → BUILD SUCCEEDED
2. Симуляторда әр экранды тексеру
3. Тест бастау → жалғастыру → аяқтау → нәтиже → тарих
4. Профиль → мамандық ауыстыру
5. Рейтинг → нақты дерек көрсету
