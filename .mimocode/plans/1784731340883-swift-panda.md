# Жоспар: Университеттің жеке беті (University Detail Page)

## Мақсат
`/universities` бетінде университет карточкасын басқанда ішкі бет ашылуы керек — логотип, атауы, қала, код, сипаттама, магистратура бағдарламалары және статистика көрсетіледі.

## Деректер құрылымы (бар)
- `data/univision_universities.json` — 125 университет: `code`, `title`, `description`, `general_info`, `edu_programs`, `students`, `teachers`, `contacts`, `logo`
- `data/univision_master_programs.json` — 154 топ: `code`, `title`, `programs[]` (әр program-да `university` аты бар)

## Қажетті өзгерістер

### 1. Жаңа файл: `src/features/specialties/UniversityDetailScreen.tsx`
**Үлгі**: `SpecialtyDetailScreen.tsx` (674 жол) — табтар, expandable карталар, dark mode

**Структура:**
```
┌─────────────────────────────────────────────┐
│ Hero: логотип + атауы + қала + код бейджі   │
├─────────────────────────────────────────────┤
│ [ЖОО туралы] [Магистратура] [Статистика]   │  ← 3 таб
├─────────────────────────────────────────────┤
│ Таб мазмұны:                                 │
│ • ЖОО туралы: сипаттама, сайт, мекенжай,   │
│   байланыс, әлеуметтік желілер              │
│ • Магистратура: осы университеттегі          │
│   магистратура бағдарламалары тізімі        │
│ • Статистика: студенттер, оқытушылар,        │
│   гранттар, бакалавриат/магистратура саны   │
└─────────────────────────────────────────────┘
```

**Негізгі логика:**
- `useParams()` арқылы университет кодын алу
- `univision_universities.json`-дан университетті табу (код бойынша)
- `univision_master_programs.json`-дан магистратура бағдарламаларын фильтрлеу (`programs[].university` аты бойынша)
- `useTheme()` арқылы dark/light mode
- `SEO` компоненті
- `AnimatePresence` + `motion` анимациялары

**Таб 1 — ЖОО туралы:**
- Логотип (бар болса) немесе әріп
- Қала + Код + Түрі + Санаты бейджілері
- Сипаттама (description + description_full)
- Мекенжайлар (contacts)
- Ресми сайт сілтемесі

**Таб 2 — Магистратура:**
- Бағдарламалар тізімі (code, title, university name)
- Іздеу жолы
- Бағдарлама саны

**Таб 3 — Статистика:**
- Студенттер саны (total, бөлінуі)
- Оқытушылар саны
- edu_programs (Бакалавриат, Магистратура, PhD, Резидентура)

### 2. Өзгеріс: `src/App.tsx`
**Lazy import қосу:**
```tsx
const UniversityDetailScreen = lazy(() => import('./features/specialties/UniversityDetailScreen'));
```

**Маршрут қосу:**
```tsx
<Route
  path="/universities/:code"
  element={
    <PanelLayout ...>
      <UniversityDetailScreen />
    </PanelLayout>
  }
/>
```

### 3. Өзгеріс: `src/features/specialties/UniversitiesScreen.tsx`
**Карточка сілтемесін өзгерту:**
- `href={uni.url}` (сыртқы сілтеме) → `onClick={() => navigate(`/universities/${uni.code}`)}` (ішкі бет)
- `target="_blank"` алып тастау

### 4. Деректер мәселесі
Университет `code` полі кейде бос болуы мүмкін. Бұл жағдайда:
- URL-де `title` slug-ін қолдану (мысалы: `/universities/astana-meditsina`)
- Немесе индекс нөмірін қолдану

**Шешім**: Кодты `code` полінен аламыз, егер бос болса — `title`-дан slug жасаймыз.

## Тексеру
1. `npm run dev` → `http://localhost:3000/universities`
2. Кез келген университет карточкасын басу → ішкі бет ашылады
3. 3 таб арасында ауысу жұмыс істейді
4. Dark/light mode дұрыс ауысады
5. Магистратура бағдарламалары көрсетіледі
6. "Артқа" батырмасы `/universities`-ке қайтарады
7. Mobile responsive — 320px-ден бастап дұрыс көрінеді
