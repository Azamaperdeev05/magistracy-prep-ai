## 2. Қосу керек функционал (Starter Story үлгілері)

### 2.1 AI Motivation Letter Generator (басты драйвер)
- Әр магистрантқа мотивациялық хат керек
- Агенттіктер 5,000-15,000 ₸ алады
- AI 1 минутта жасайды
- Pro tier-ге кіреді

### 2.2 AI Essay Checker
- IELTS/магистратура эсселерін тексеру
- Grammar, style, score prediction
- Pro tier-ге кіреді

### 2.3 Smart Study Plan (Hero Analytics үлгісі)
- Тест нәтижелері бойынша әлсіз жақтарды талдау
- Жеке оқу жоспары
- Premium+ tier

## 3. Төлемді автоматтандыру

### 3.1 Kaspi QR автоматты төлем
- Kaspi бизнес кабинетіне тіркелу
- API арқылы төлемді растау
- Firebase-те is_premium автоматты қосу

### 3.2 Stripe (шетелдік студенттер үшін)
- $6/ай = ~2,700 ₸
- Толық автоматтандырылған

### 3.3 Kaspi + WhatsApp (уақытша шешім)
- Қазіргідей қолмен
- Бірақ admin панелін қосу керек
